# **App Name**: Medlight Dashboard

## Core Features:

- User Authentication: Secure user sign-up and login using Firebase Authentication.
- Building Information Collection: Collect general building information: name, address, type, dimensions, contact details etc.
- Electrical Installation Details: Capture electrical setup: number of wires, amperage, components, photos.
- Audit Configuration: Configure the audit: date, building name, level information.
- Equipment Inventory: Inventory of equipment: type, name, quantity, photos, electrical characteristics.
- Energy Consumption Calculation: Calculate energy usage based on daytime/nighttime hours, weekdays/weekends.
- Data Visualization and Reporting: Display total power installed, monthly/annual energy, diurnal/nocturnal energy, and graphical representations. Generate PDF and Excel reports.
- Real-time Data Display: Display the data in real time from Firestore to the user interface.

## Style Guidelines:

- Primary color: Deep teal (#008080) evoking reliability and professionalism.
- Background color: Light gray (#F0F0F0) for a clean, modern aesthetic.
- Accent color: Gold (#FFD700) to highlight important metrics and interactive elements.
- Body and headline font: 'Inter' sans-serif font providing a clean and readable experience.
- Use modern, minimalist icons to represent different data categories and functionalities.
- Implement a responsive grid layout to adapt to different screen sizes, maintaining a consistent look and feel across devices, and align with the Creative Tim dashboard style.
- Incorporate subtle animations for loading states and data updates to improve user engagement.
